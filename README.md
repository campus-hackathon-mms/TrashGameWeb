# TrashJudgement（ゴミ分別ゲーム）

画面に流れてくるゴミを分解して、正しいゴミ箱に分別するアクションゲームです。
**選んだ自治体の実際の分別ルールによって、正解が変わります。**

## 遊ぶ

https://campus-hackathon-mms.github.io/TrashGameWeb/

ブラウザでそのまま遊べます（スマートフォンの Safari / Chrome、PC のブラウザ）。
スマートフォンは縦持ちがおすすめです。

**遊び方・ルール・展示の方への案内は [説明書（MANUAL.md）](MANUAL.md) を見てください。**

## このリポジトリについて

ゲームの WebGL 版を公開するためのリポジトリです。
`site` フォルダに置いたビルドを、[GitHub Actions](.github/workflows/deploy-pages.yml) で GitHub Pages に公開しています。
